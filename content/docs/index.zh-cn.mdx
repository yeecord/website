## 两种安装方式

| 安装方式 | 说明 |
| -------- | ---- |
| 加入服务器 | 整个服务器的成员都能使用 |
| 安装到账号 | 装在你自己的 Discord 账号上，私信、群组私信、任何服务器都能用 |

Discord 会在安装时让你选择，两种方式可以同时使用

安装到账号后，<Cmd name="poll" />、<Cmd name="find-food" /> 等支持的命令也能在没有安装机器龙的地方使用
