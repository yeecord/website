---
title: 模板
description: 成员通知的内容和动态语音的房间名称都能放变量，发送时换成实际的成员、服务器和时间。
---

成员通知的内容和[动态语音](./commands/auto-channels.mdx)的房间名称都是模板。模板里用大括号写变量，机器龙发送时会换成实际的值。例如这段加入通知：

```txt
欢迎 {user.mention} 加入 {server.name}，你是{server.member_count:ordinal} 位成员！
```

有人加入时会变成：

<DiscordChat>
  <DiscordMessage>
    <p>欢迎 <Mention>@新成员</Mention> 加入 YEE 式服务器，你是第 1,234 位成员！</p>
  </DiscordMessage>
</DiscordChat>

## 查看能用的变量

成员通知的状态面板和动态语音的大厅面板上都有一个“模板变量”按钮。按下去会打开一页只有你看得到的列表，列出那个地方能用的每个变量，旁边是用你自己代入的结果。列表最下面的“完整说明”会链接回这一页。

## 变量

变量写成 `{种类.字段}`，种类有用户 `user`、服务器成员 `member`、服务器 `server` 和时间 `time`：

| 变量 | 发送时换成 |
| ---- | ---- |
| `{user.name}` | 成员的显示名称，没设就是用户名 |
| `{user.username}` | 用户名 |
| `{user.id}` | 用户 ID |
| `{user.mention}` | 标注成员，但不会发出通知 |
| `{user.avatar}` | 头像链接 |
| `{user.bot}` | 是不是机器人 |
| `{user.created}` | 账号创建时间 |
| `{member.nick}` | 服务器昵称，没设就是空的 |
| `{member.display}` | 服务器昵称，没设就是显示名称 |
| `{member.joined}` | 加入服务器的时间 |
| `{server.name}` | 服务器名称 |
| `{server.id}` | 服务器 ID |
| `{server.icon}` | 服务器图标链接 |
| `{server.member_count}` | 目前的成员人数 |
| `{time.now}` | 发送的时间 |

## 成员通知和房间名称的区别

两个地方能用的变量不完全一样，因为频道名称只能放一行纯文本：

| | 成员通知 | 房间名称 |
| ---- | ---- | ---- |
| `{user.mention}` | 标注成员 | 不能用 |
| `{user.avatar}`、`{server.icon}` | 链接 | 不能用 |
| `{member.nick}`、`{member.joined}` | 加入通知能用，离开通知不能用 | 能用 |
| 时间 | 每个人自己时区的时间，可以换格式 | 按服务器语言排列的日期，例如 2026/11/8 |
| 换行 | 保留 | 去掉 |

成员离开后，机器龙就拿不到他在服务器里的昵称和加入时间，所以离开通知不能用 `{member.nick}` 和 `{member.joined}`。

## 时间格式

成员通知里的时间会显示成每个人自己时区的完整日期时间，`{user.created}` 则是“3 年前”这种相对时间。在变量后面加 `:` 和一个字母可以换格式，例如 `{member.joined:R}`：

| 字母 | 样子 |
| ---- | ---- |
| `t` | 20:30 |
| `T` | 20:30:00 |
| `d` | 2026/11/08 |
| `D` | 2026年11月8日 |
| `f` | 2026年11月8日 20:30 |
| `F` | 2026年11月8日星期日 20:30 |
| `R` | 3 年前 |

## 序数

`{server.member_count:ordinal}` 会把人数写成序数，中文是“第 1,234”，英文是“1,234th”。

## 随机

这两个写法每次发送都会重新抽：

| 写法 | 发送时换成 |
| ---- | ---- |
| `{choose:早安\|午安\|晚安}` | 用 `\|` 隔开的其中一个，每次随机 |
| `{range:1-6}` | 1 到 6 之间的整数，每次随机 |

## 打出大括号

在大括号前面加反斜杠就会按原样显示，例如 `\{user.name}` 会显示成 `{user.name}`。

## 保存时的检查

保存前机器龙会先读一遍模板：

- 用了这个地方拿不到的变量，例如在离开通知用 `{member.joined}`，或在房间名称用 `{user.mention}`，设置不会变更。
- 机器龙不认识的名字会按原样显示。保存会成功，但机器龙会提醒你，打错字的话还会猜你想打哪一个。
- 一个模板最多放 50 个变量。

## 旧的写法

旧的 `{user}`、`{mention}`、`{server}`、`{member_count}` 还能用，分别等于 `{member.display}`、`{user.mention}`、`{server.name}`、`{server.member_count}`。已经保存的模板不用改。
