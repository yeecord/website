每个斜杠命令都能单独设权限。这是 Discord 内置功能，改完立即生效，机器龙不用重开。

<CommandPermissionsDemo />

## 怎么改

1. 打开「服务器设置」，选「整合」。
2. 在「机器人和应用」找到 Yeecord，按「管理」。
3. 点你要调整的命令。
4. 加上覆写：选身份组、成员或频道，设成允许或拒绝。

手机版一样：长按服务器名称 → 设置 → 整合。

## 常见用法

| 想做的事 | 怎么设 |
| --- | --- |
| `/clear` 只给管理组用 | 在 `/clear` 拒绝 @everyone，允许 @管理组 |
| 娱乐命令锁在机器人区 | 在该命令拒绝所有频道，允许 #机器人区 |
| 完全关掉某个命令 | 在该命令拒绝 @everyone |

## 两件事别搞混

- 这页改的是「谁能叫命令」。机器龙执行时用的是[安装时勾的权限](/install)，例如 `/clear` 还是要有「管理消息」才删得了东西。
- 没被允许的人打 `/`，清单里直接看不到那个命令，不会出现按了才报错的情况。
