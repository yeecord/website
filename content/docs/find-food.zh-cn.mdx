## 觅食

选一个地点出门后，袋子会随时间装满

大约一天半到两天后回来收成，才会知道这趟带回什么

- 食材有普通、稀有、传说三种稀有度
- 每个地点每天轮换情报，提示今天容易捡到什么
- 有保底机制：连续几次没遇到新食材，之后几次内必定遇到
- 偶尔会捡到惊喜，也会看到其他玩家最近的收获足迹
- 路上会碰到小事件，选不同的分支有不同结果

## 烹饪

从背包挑几样食材下锅，Yee 会评分：

| 评级 | 说明 |
| ---- | ---- |
| 普通 | 能吃 |
| 好吃 | 食材搭配得不错 |
| 绝品 | 完美组合 |

食材搭配不对会煮出黑暗料理

黑暗料理也有自己的隐藏菜谱

每天有一个「今日想吃」的风味提示，只给方向不给答案，照着方向煮容易拿高分。

## 菜谱与喂养

- 菜谱会记录你煮过的料理
- 喂 Yee 可以累积感情，解锁更多互动
- 分享成绩会生成一张卡片

## 铜板

觅食和烹饪会获得铜板

铜板只在游戏内使用，不能和其他玩家交易

- 在 [top.gg 投票](https://top.gg/bot/584213384409382953/vote) 也会获得铜板
- 每 12 小时可以投一次，周末一票算两票
- 奖励会直接存进钱包
