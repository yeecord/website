文档都在 GitHub 上的 [yeecord/website](https://github.com/yeecord/website)，每页右边都有「编辑此页」可以直接改。

## 新增页面

在 `content/docs/` 建立 MDX 文件，开头一定要有 frontmatter：

```mdx title="my-page.mdx"
---
title: 你的标题
description: 这一页在讲什么？
---

正文...
```

新页面要加进同目录的 `meta.json` 才会出现在侧栏：

```json
{
  "pages": ["index", "my-page"]
}
```

博客文章放在 `content/blog/`，多了 `authors`、`date`、`tags` 字段，作者信息定义在 `config.ts` 的 `blogAuthors`。

## 写作原则

- 用表格和标题，不要一大坨文字
- 假设读者可能没用过 Discord，术语第一次出现时链到 [新手入门](../basics.mdx)
- 展示命令用 `<SlashCommand />`、模拟机器人回复用 `<DiscordChat />`，不用截图
- 中英文和数字之间留空格，照 [中文文案排版指北](https://github.com/sparanoid/chinese-copywriting-guidelines)
- 不要自我宣传、不带政治立场

MDX 的其他功能可以参考 [fumadocs 的文档](https://fumadocs.dev/docs/ui/markdown)。
