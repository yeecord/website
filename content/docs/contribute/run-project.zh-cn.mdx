---
title: 在本地运行项目
description: 在自己的电脑上运行文档网站，实时预览你的修改。
---

网站用 [fumapress](https://press.fumadocs.dev) + [Waku](https://waku.gg) 打造，内容都是 MDX 文件。改文档其实不需要跑起来，但想实时预览的话照下面做。

## 需要的工具

- 任何代码编辑器，推荐 [Visual Studio Code](https://code.visualstudio.com/)
- [Bun](https://bun.sh)：这个项目的运行环境跟包管理器

安装 Bun 之后确认一下版本：

```bash
bun -v
```

## 跑起来

```bash
git clone https://github.com/yeecord/website.git
cd website
bun install
bun dev
```

打开终端显示的网址就能看到网站，改动 `content/` 里的文件会实时刷新。

## 构建检查

提 PR 前跑一次，确定没有坏掉的类型或链接：

```bash
bun run typecheck
bun run build
```
