每個斜線指令都能單獨設權限。這是 Discord 內建功能，改完立即生效，機器龍不用重開。

<CommandPermissionsDemo />

## 怎麼改

1. 打開「伺服器設定」，選「整合」。
2. 在「機器人和應用程式」找到 Yeecord，按「管理」。
3. 點你要調整的指令。
4. 加上覆寫：選身分組、成員或頻道，設成允許或拒絕。

手機版一樣：長按伺服器名稱 → 設定 → 整合。

## 常見用法

| 想做的事 | 怎麼設 |
| --- | --- |
| `/clear` 只給管理組用 | 在 `/clear` 拒絕 @everyone，允許 @管理組 |
| 娛樂指令鎖在機器人區 | 在該指令拒絕所有頻道，允許 #機器人區 |
| 完全關掉某個指令 | 在該指令拒絕 @everyone |

## 兩件事別搞混

- 這頁改的是「誰能叫指令」。機器龍執行時用的是[安裝時勾的權限](/install)，例如 `/clear` 還是要有「管理訊息」才刪得了東西。
- 沒被允許的人打 `/`，清單裡直接看不到那個指令，不會出現按了才報錯的情況。
