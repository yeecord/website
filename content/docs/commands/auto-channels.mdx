---

為了不同用途開一堆語音頻道，像是 `遊戲用`、`聽音樂用`，頻道一多列表就會很亂。

動態語音頻道只需要一個「大廳」：成員加入時，機器龍自動開一間專屬於他的「房間」並把他移過去；房間沒人之後自動刪除。

## 安裝

<SlashCommand
  name="auto-channels setup"
  options={[{ name: "channel", value: "#創建頻道", required: true }]}
  description="把一個語音頻道設為大廳"
/>

選一個現有的語音頻道當大廳就完成了。每個伺服器最多設 2 個大廳，房間不能再被設為大廳。

結果只有你看得到。對已經是大廳的頻道再跑一次 `setup`，房間名稱、人數上限和音質會維持原樣。

## 房主權限

開房的人自動拿到自己房間的「管理頻道」和「移動成員」權限，可以直接用 Discord 介面改名、設人數上限、把人踢出語音。權限只在這個房間有效，房間刪除就跟著消失。

## 保留房間

房間預設沒人就刪。想留下某個房間（例如已經佈置好權限的），用：

<SlashCommand
  name="auto-channels keep"
  options={[{ name: "channel", value: "#隊聚頻道", required: true }]}
  description="讓這個房間不會被自動刪除"
/>

結果只有你看得到。只能保留大廳開出來的房間。

## 查看清單

<SlashCommand
  name="auto-channels list"
  description="開啟大廳面板"
/>

面板只有你看得到，列出伺服器裡所有大廳，以及各自目前的房間。每個大廳旁有兩顆按鈕：

| 按鈕 | 作用 |
| ---- | ---- |
| 設定 | 修改房間名稱、人數上限和音質 |
| 解除安裝 | 把這個頻道移出大廳 |

房間名稱裡的 `%user%` 會換成成員名稱。人數上限填 0 代表不限，最多 99 人。音質可選標準或最高。

大廳缺少權限時，面板會告訴你機器龍還需要開哪些權限。

## 解除安裝

<SlashCommand
  name="auto-channels remove"
  options={[{ name: "channel", value: "#創建頻道", required: true }]}
  description="解除安裝大廳"
/>

也可以在大廳面板按「解除安裝」。

機器龍會先確認。目前有房間時，你可以選：

| 按鈕 | 結果 |
| ---- | ---- |
| 刪除房間 | 房間一併刪除，裡面的人會斷線 |
| 保留房間 | 房間改為一般語音頻道 |

大廳頻道本身不會被刪除。
