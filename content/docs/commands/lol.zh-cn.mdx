<Cmd name="lol" /> 查询英雄联盟的玩家信息，战绩卡片会画成图片。

目前只查得到台港澳服务器的玩家。查其他服务器的玩家时，机器龙会告诉你查不到的原因。

Riot 暂时没有回应时，回复会附「重试」按钮，按下去用同样的条件再查一次。

<CommandHeader />

## 绑定账号

<SlashCommand
  name="lol link"
  options={[{ name: "name", value: "Hide on bush#KR1", required: true }]}
  description="绑定你的 Riot ID，格式是 名称#Tag"
/>

绑定结果只有你看得到。

重新绑定时，回复会告诉你替换了哪个账号。

绑定后其他子命令的 `name` 都可以留空，直接查自己。还没绑定时，回复会附「绑定账号」按钮，点下去填 Riot ID 就能绑。

## 查询

| 命令 | 说明 |
| ---- | ---- |
| <Cmd name="lol player" /> | 玩家卡片：第一行是段位，附单双排／灵活组排积分和英雄专精，下面有「近期战绩」「即时对局」按钮 |
| <Cmd name="lol matches" /> | 最近 10 场战绩，只有你看得到 |
| <Cmd name="lol live" /> | 正在进行的对局 |
| <Cmd name="lol rotation" /> | 本周免费轮换英雄，按英雄分类列出 |

## 近期战绩

<Cmd name="lol matches" /> 会列出最近 10 场。从菜单选一场，就能看完整的对战卡。

对战卡默认只有你看得到。点「分享这场」才会发到频道，频道里只会看到这一场的对战卡。

## 即时对局

<Cmd name="lol live" /> 显示队列类型、开打时间，以及双方每位玩家的英雄和 Riot ID。

局势会一直变，点「刷新」更新。玩家没在游戏里时，会告诉你对方上一场什么时候结束。
