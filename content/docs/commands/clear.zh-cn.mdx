<Cmd name="clear" /> 大量删除频道消息。删除任务会排进队列在后台执行，就算要删 1000 条也不用等它跑完。

<CommandHeader you={["管理消息"]} bot={["管理消息", "阅读历史消息"]} />

## 新增删除任务

<SlashCommand
  name="clear add"
  options={[
    { name: "amount", value: "100", required: true },
    { name: "user", value: "@某人" },
  ]}
  description="删除这个频道最近的 100 条消息，加 user 参数就只删他的"
/>

| 参数 | 必填 | 说明 |
| ---- | ---- | ---- |
| `amount` | ✅ | 要删的数量，1 到 1000 |
| `user` | | 只删这位成员的消息 |
| `authors` | | 只删机器人、或只删真人的消息 |
| `contains` | | 只删内容包含这段文字的消息，不分大小写 |
| `with` | | 只删带链接、或带附件的消息 |

筛选条件可以叠加，全部成立才会删。置顶消息一律跳过，不用担心公告被清掉。超过 14 天的消息 Discord 不允许批量删除，也会跳过。

要删超过 100 条时，机器龙会先问你确认。确认界面列出频道、范围和筛选条件，点「删除 N 条消息」才会开始。删掉的消息无法恢复。

开始后，进度会在同一条只有你看得到的消息里更新。想中途停下，点「停止」。已删除的消息不会恢复，没删的会保留。

任务结束后，频道会收到一则通知。如果实际删除的数量比设置的少，通知会说明可能的原因。

## 中断后继续

机器龙失去频道的「管理消息」权限，或任务被中断时，通知会写出已删除多少条。补上权限后，点「继续删除」就能接着删剩下的。

## 管理队列

| 命令 | 说明 |
| ---- | ---- |
| <Cmd name="clear list" /> | 查看进行中和排队中的任务，包括剩余数量，每条写明是谁添加的。进行中的任务旁有「停止」，排队中的有「取消」，可以只处理那一个。下面有「全部停止」 |
| <Cmd name="clear flush" /> | 停止服务器里所有还没跑完的任务，包括其他管理员排的。会先请你确认，点下「停止 N 条任务」才会执行 |

停止、取消和继续删除，都需要你在那个频道有 **管理消息** 权限。没有的话，机器龙会请管理员在该频道开启后再试一次。
