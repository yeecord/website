<Cmd name="member-notification" /> 設定成員加入、離開伺服器時的通知訊息。

<CommandHeader you={["管理伺服器"]} />

## 設定

<SlashCommand
  name="member-notification"
  options={[{ name: "type", value: "join", required: true }]}
  description="type 選 join 設定加入通知、leave 設定離開通知"
/>

執行後會跳出表單：

| 欄位 | 說明 |
| ---- | ---- |
| 啟用狀態 | 開或關 |
| 發送頻道 | 通知要發到哪個文字頻道 |
| 訊息內容 | 最多 2000 字，支援 Markdown |
| 圖卡 | 不出圖卡，或選一種樣式附在通知下面 |

訊息內容裡可以放變數：

| 變數 | 發送時換成 |
| ---- | ---- |
| `{user}` | 成員名稱，純文字 |
| `{mention}` | 標註成員，對方會收到通知 |

<DiscordChat>

儲存並啟用後，機器龍會用你本人代入變數，回一則只有你看得到的預覽，不用等真的有人進來才能確認。

## 圖卡

選了圖卡樣式，通知文字下面會多一張圖：成員頭像、名字、伺服器名，加入時寫第幾位成員，離開時寫現有人數。

| 樣式 | 長相 |
| ---- | ---- |
| 招牌 | 大頭像在左，名字當招牌字，紅色「歡迎光臨」標籤 |
| 入場券 | 左邊紅色票根印「入場券 No. 1234」，虛線撕邊，右邊是成員資料 |
| 印章 | 置中版面，名字下面蓋一顆紅印「歡迎」 |

離開通知用同一套樣式，字會換成道別的版本。圖卡的文字跟著伺服器的語言設定走。

想關掉就重跑指令，圖卡選「不出圖卡」。

加入跟離開的訊息分開設定，各跑一次指令就好。

## 用頻道訊息當範本

標註、表情、換行在頻道的輸入框裡打比在表單裡順手。先在任一頻道把通知打好、送出，再對那則訊息按右鍵 → Apps →「設為範本」。

會跳出同一張設定表單，訊息內容已經填好，多一個「用途」欄位選加入通知或離開通知。打完的那則訊息可以自己刪掉。

<Callout type="warn">
  發送頻道被刪掉、或機器龍看不到那個頻道的時候，通知會自動關閉。頻道被刪了就重跑指令換一個；還在的話，到頻道權限把機器龍這兩項打開，再跑一次指令重新啟用：

  <ChannelPermissionDemo
    title="頻道設定 → 權限 → YEE式機器龍"
    permissions={[
      { name: "檢視頻道", enabled: true },
      { name: "發送訊息", enabled: true },
    ]}
    caption="兩個都開，機器龍才能在這個頻道發通知"
  />
</Callout>
