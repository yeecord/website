<Cmd name="member-notification" /> 設定成員加入、離開伺服器時的通知訊息。

<CommandHeader you={["管理伺服器"]} />

## 設定

<SlashCommand
  name="member-notification"
  options={[{ name: "type", value: "join", required: true }]}
  description="type 選填。不填會開啟狀態面板，選 join 或 leave 直接設定那一種通知"
/>

不帶選項時，會開啟只有你看得到的狀態面板，一次看到加入通知和離開通知的狀態：

| 狀態 | 面板上的按鈕 |
| ---- | ------------ |
| 還沒設定 | 設定 |
| 開啟中 | 編輯、停用 |
| 已停用 | 編輯、開啟。內文與圖卡都還留著，按「開啟」就能恢復 |
| 頻道失效而自動停用 | 編輯、重新啟用。面板會寫出原因 |

按「設定」或「編輯」會跳出表單。「編輯」會帶入舊值，只改想改的地方就好：

| 欄位 | 說明 |
| ---- | ---- |
| 頻道 | 通知要發到哪個文字頻道 |
| 通知內文 | 最多 2000 字，支援 Markdown |
| 圖卡 | 不出圖卡，或選一種樣式附在通知下面 |

訊息內容裡可以放變數，狀態面板下方也會列出來：

| 變數 | 發送時換成 |
| ---- | ---- |
| `{user.name}` | 成員的顯示名稱，沒設就是使用者名稱 |
| `{user.username}` | 使用者名稱 |
| `{user.id}` | 使用者 ID |
| `{user.mention}` | 標註成員，對方會收到通知 |
| `{user.avatar}` | 頭像網址 |
| `{user.bot}` | 是不是機器人 |
| `{user.created}` | 帳號建立時間 |
| `{member.nick}` | 伺服器暱稱，沒設就是空的 |
| `{member.display}` | 伺服器暱稱，沒設就是顯示名稱 |
| `{member.joined}` | 加入伺服器的時間 |
| `{server.name}` | 伺服器名稱 |
| `{server.id}` | 伺服器 ID |
| `{server.icon}` | 伺服器圖示網址 |
| `{server.member_count}` | 目前的成員人數 |
| `{time.now}` | 發送的時間 |

成員離開後就沒有 `{member.nick}` 和 `{member.joined}`，離開通知用了它們會存不進去。

時間預設顯示成每個人自己時區的完整日期時間，`{user.created}` 則是「3 年前」這種相對時間。在後面加 `:` 和一個字母可以換格式，例如 `{member.joined:R}`：

| 字母 | 樣子 |
| ---- | ---- |
| `t` | 下午 8:30 |
| `T` | 下午 8:30:00 |
| `d` | 2026/11/08 |
| `D` | 2026年11月8日 |
| `f` | 2026年11月8日 下午 8:30 |
| `F` | 2026年11月8日星期日 下午 8:30 |
| `R` | 3 年前 |

`{server.member_count:ordinal}` 會寫成序數，中文是「第 1,234」，英文是「1,234th」。

另外有兩個隨機的寫法：

| 寫法 | 發送時換成 |
| ---- | ---- |
| `{choose:早安\|午安\|晚安}` | 用 `\|` 隔開的其中一個，每次隨機 |
| `{range:1-6}` | 1 到 6 之間的整數，每次隨機 |

想打出大括號本身就寫 `\{`。機器龍不認得的名字會照原樣顯示，存檔時會提醒你，打錯字的話還會猜你想打哪一個。

舊的 `{user}`、`{mention}`、`{server}`、`{member_count}` 還能用，分別等於 `{member.display}`、`{user.mention}`、`{server.name}`、`{server.member_count}`。

儲存後通知會開啟，機器龍會用你本人代入變數，回一則只有你看得到的預覽，不用等真的有人進來才能確認。

## 圖卡

選了圖卡樣式，通知文字下面會多一張圖：成員頭像、名字、伺服器名，加入時寫第幾位成員，離開時寫現有人數。

| 樣式 | 長相 |
| ---- | ---- |
| 招牌 | 大頭像在左，名字當招牌字，紅色「歡迎光臨」標籤 |
| 入場券 | 左邊紅色票根印「入場券 No. 1234」，虛線撕邊，右邊是成員資料 |
| 印章 | 置中版面，名字下面蓋一顆紅印「歡迎」 |

離開通知用同一套樣式，字會換成道別的版本。圖卡的文字跟著伺服器的語言設定走。

想關掉就重跑指令，圖卡選「不出圖卡」。

加入跟離開的訊息分開設定，各跑一次指令就好。

## 用頻道訊息當範本

標註、表情、換行在頻道的輸入框裡打比在表單裡順手。先在任一頻道把通知打好、送出，再對那則訊息按右鍵 → Apps →「設為範本」。

會跳出同一張設定表單，內文已經填好，多一個「用途」欄位選加入通知或離開通知。打完的那則訊息可以自己刪掉。

<Callout type="warn">
  發送頻道被刪掉、或機器龍無法在那個頻道發訊息的時候，通知會自動停用，狀態面板會寫出原因和是從什麼時候開始的。頻道被刪了就按「編輯」換一個；還在的話，到頻道權限把機器龍這兩項打開，再按「重新啟用」：
