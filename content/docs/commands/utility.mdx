## 圖片卡片

這些指令會回傳圖片卡片：

| 指令 | 說明 |
| ---- | ---- |
| <Cmd name="quote" /> | 把某人最近的訊息做成名言圖片 |
| <Cmd name="fortune" /> | 抽今天的籤詩，同一天的結果相同 |
| <Cmd name="compat" /> | 看兩位成員的相性 |
| <Cmd name="fake" /> | 把文字做成新聞、聊天截圖、搜尋結果或感謝狀 |

<Cmd name="fortune" /> 的籤詩會印上抽籤的人，底下有「我也抽」按鈕，其他人按了就能抽自己的。

<Cmd name="compat" /> 的圖片上方寫著兩個人的名字和分數。結果不會通知被算的那個人。

<Cmd name="fake" /> 做好後先給你私人預覽。按「分享」才會發到頻道，圖片下方會註明是你做的。超過字數上限的部分會被截掉，預覽會告訴你。

<Cmd name="quote" /> 也能從右鍵選單使用

對訊息按右鍵，手機則長按，選「應用程式」後再選 **quote-message**

用指令引用時，機器龍只會找對方最近 100 則訊息。找不到的話，回覆會說明這個範圍，並教你改用右鍵選單引用更早的訊息

## 查詢

| 指令 | 說明 |
| ---- | ---- |
| <Cmd name="status" /> | 機器龍狀態：延遲、伺服器數、帳號安裝數、運行時間 |
| <Cmd name="guild" /> | 目前伺服器的資訊：成員數、擁有者、建立日期和加成等級 |
| <Cmd name="avatar" /> | 取得使用者頭貼原圖（2048px），預設顯示伺服器頭貼 |
| <Cmd name="banner" /> | 取得使用者旗幟原圖 |
| <Cmd name="minecraft player" /> | Minecraft 玩家資訊，可綁定自己的 ID |
| <Cmd name="minecraft server" /> | Minecraft 伺服器狀態，顯示在線人數 |

<Cmd name="avatar" /> 的對象有設定伺服器頭貼時，預設顯示那一張。底下的按鈕可以切換成個人頭貼，或開啟原圖。

<Cmd name="minecraft player" /> 還沒綁定時，回覆會說明怎麼綁：在指令填入玩家名稱，再按「綁定帳號」。綁定後不填名稱就會查自己。

<Cmd name="minecraft server" /> 的結果可以按「重新查詢」更新。

## 娛樂

| 指令 | 說明 |
| ---- | ---- |
| <Cmd name="pick" /> | 丟一個問題，機器龍幫你選答案，回覆會先引用你的問題 |
| <Cmd name="random number" /> | 抽一個範圍內的整數 |
| <Cmd name="random voice-channel" /> | 從語音頻道隨機抽一位成員 |
| <Cmd name="1a2b" /> | 1A2B 猜數字，5 種難度 |
| <Cmd name="bullshit" /> | 道歉文、情書唬爛產生器，可指定字數 |

<Cmd name="1a2b" /> 的每次猜測都在同一則訊息裡更新，並列出完整的猜測紀錄。

<SlashCommand
  name="bullshit"
  options={[
    { name: "topic", value: "遲到的道歉文", required: true },
    { name: "length", value: "500" },
  ]}
  description="產生一篇 500 字的唬爛文，超過 1500 字會用文字檔附上"
/>

`topic` 最多 50 字。產生後先給你私人預覽，底下有兩顆按鈕：

| 按鈕 | 作用 |
| ---- | ---- |
| 換一篇 | 用同一個主題重寫一篇 |
| 分享 | 發到頻道，並註明作者是你 |

文章太長時，會改成文字檔附上，分享出去的也是那份檔案。

## 伺服器與帳號

| 指令 | 說明 |
| ---- | ---- |
| <Cmd name="language" /> | 設定機器龍在這個伺服器用的語言，需要 **管理伺服器** 權限 |
| <Cmd name="afk-channel" /> | 讓機器龍一直待在某個語音頻道，需要 **管理伺服器** 權限 |
| <Cmd name="delete-data" /> | 刪除你存在機器龍這裡的資料 |
| <Cmd name="help" /> | 看機器龍有哪些指令 |

### 語言

<Cmd name="language" /> 不帶選項時，會顯示目前的設定：用哪種語言，或是跟隨每個人的 Discord 語言。選「跟隨 Discord」會回到各自的語言設定。

### 待命頻道

`afk-channel` 有三個子指令：

| 子指令 | 說明 |
| ---- | ---- |
| `set` | 讓機器龍待在指定的語音頻道。設定前會檢查機器龍在那個頻道有沒有「連接」權限 |
| `show` | 看機器龍目前待在哪個頻道 |
| `clear` | 讓機器龍離開 |

這個頻道和 Discord 伺服器設定裡的 AFK 頻道無關。

### 刪除資料

<SlashCommand name="delete-data" description="刪除你存在機器龍這裡的資料" />

機器龍會先列出各類資料各有幾筆：帳號綁定、遊戲資料和舊資料。選好要刪的類別後，按「刪除」就會執行，不需要再輸入文字。

刪除後資料會保留 30 天備份，只用來救回誤刪。需要的話，到支援伺服器申請。投票、表單、抽獎這類伺服器共用的紀錄不會刪除。

### 幫助

<SlashCommand name="help" description="開啟幫助面板" />

面板只有你看得到。首頁列出大多數伺服器常用的指令，下拉選單可以依分類查看：管理與防護、迎新與身分組、語音頻道、活動、小遊戲與趣味、小工具，以及機器龍本身。

「這個伺服器的設定」頁會列出目前開啟的功能，例如陷阱頻道、動態語音頻道和新成員身分組，以及哪些功能出了問題。只有 **管理伺服器** 權限的人看得到這一頁。

面板底下有使用說明、邀請和支援群組的連結。
