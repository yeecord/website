---
title: 抽獎
description: 在伺服器舉辦抽獎活動，可以限制參加資格、設定自動開獎時間。
---

<Cmd name="giveaway" /> 讓你在伺服器舉辦抽獎，成員點一顆按鈕就能參加，時間到自動開獎。

<CommandHeader you={["管理伺服器"]} />

## 建立抽獎

<SlashCommand
  name="giveaway create"
  options={[
    { name: "amount_of_winners", value: "3", required: true },
    { name: "title", value: "Nitro 抽獎", required: true },
    { name: "end_in", value: "7d" },
  ]}
  description="建立一場 7 天後開獎、抽出 3 位得獎者的抽獎"
/>

| 參數 | 必填 | 說明 |
| ---- | ---- | ---- |
| `amount_of_winners` | ✅ | 獲獎人數 |
| `title` | ✅ | 標題，最多 100 字 |
| `mention` | | 發布時標註的身分組。身分組要開「允許任何人提及這個身分組」，成員才會收到通知，不然只會顯示標註、不會響 |
| `description` | | 描述，最多 1000 字 |
| `end_in` | | 多久後自動開獎，例如 `7d`，留空表示手動開獎 |
| `minimum_join_time` | | 加入伺服器多久後才能參加，防小號 |
| `allowed_role` | | 限定某個身分組才能參加 |
| `image` | | 大圖 |
| `thumbnail` | | 縮圖 |

<GiveawayFlowDemo />

有設 `end_in` 的話，抽獎訊息會寫出確切的開獎時間。有限定身分組或加入時間的話，也會一起列出來。不符合條件的成員按下參加，會被擋下並收到原因。

## 參加與退出

成員按「點我參加」後，會收到只有自己看得到的回覆，寫明目前有幾人參加、什麼時候抽獎，以及結果會公布在哪個頻道。

想退出，按「退出抽獎」。抽獎結束前，隨時可以再按「點我參加」重新加入。

抽獎卡片會顯示目前的參加人數。結束後，改顯示得獎者。

## 提前開獎

<SlashCommand
  name="giveaway end"
  options={[{ name: "giveaway", value: "Nitro 抽獎", required: true }]}
  description="現在就抽出得獎者"
/>

只有發起人與有 **管理伺服器** 權限的人能用。機器龍會先確認，按「現在抽獎」才會抽。抽出後不能撤回。

抽獎卡片上的「終止抽獎」按鈕也一樣，會先確認。

## 重新傳送

抽獎訊息被洗版時，用 <Cmd name="giveaway resend" /> 把它重新傳到最下面，`giveaway` 參數有自動補全。已結束的抽獎也能重傳，結果卡不會因為被洗版就找不回來。

## 重抽得獎者

得獎者棄權或資格不符時，用 <Cmd name="giveaway reroll" /> 從還沒中獎的參加者裡再抽一次，結果會公告在原本的抽獎頻道，回覆也會寫出這次抽中誰。`amount_of_winners` 留空只補抽 1 位。只能重抽自己建立、已經結束的抽獎。
