<Cmd name="form" /> 用来建立举报、申请或客服表单

成员从面板填完表单后，机器龙会开一个私密子区，把填表的人和管理员加入子区

## 创建

<SlashCommand name="form create" description="弹出表单，填标题和通知对象" />

填完基本资料后，机器龙会发一张只有你看得到的管理卡

| 字段 | 说明 |
| ---- | ---- |
| 标题 | 最多 45 字，也是成员填表窗口的标题 |
| 说明 | 选填，会显示在面板消息上 |
| 按钮文字 | 选填，不填就叫「填写」 |
| 通知身份组 | 选填，最多 5 个，有人提交表单时会提及他们。身份组要开「允许任何人提及此身份组」才会收到通知，不然只会显示提及、不会响 |

没选通知身份组时，管理卡会警告你：新申请不会通知任何人。到「设置」加上身份组就能解决

## 管理卡

管理卡上有这些按钮，随时可以用 <Cmd name="form edit" /> 选一张已有表单，重新打开管理卡

| 按钮 | 作用 |
| ---- | ---- |
| 发布 | 在卡片上选频道，把填写面板发过去 |
| 设置 | 修改标题、说明、按钮文字和通知身份组 |
| 新增题目 | 加一道题目 |
| 调整题目 | 修改题目内容，或上下移动顺序 |
| 停用／启用 | 暂停或恢复接受新申请 |

## 编辑题目

Discord 的表单窗口最多 5 题

题目分三种：

| 类型 | 说明 |
| ---- | ---- |
| 短答 | 一行文字 |
| 段落 | 多行文字，适合「请描述发生什么事」这种题目 |
| 单选 | 下拉菜单，选项填 2 到 25 个，用逗号或换行分隔 |

已发布的表单仍可改题目，成员下次点面板时会看到最新版本

## 发布

<SlashCommand name="form send" description="选择表单和文字频道，发布填写面板" />

也可以在管理卡点「发布」，在卡片上选频道。你必须在那个频道有「管理频道」权限

同一张表单可以发到多个文字频道。发布时会写明新申请会通知谁

## 暂停与恢复

| 命令 | 用途 |
| ---- | ---- |
| <Cmd name="form disable" /> | 暂停接受新回复，已有面板会保留 |
| <Cmd name="form enable" /> | 恢复接受新回复 |

管理卡上的「停用」「启用」也一样。已发布的面板会跟着更新，停用后成员点下去会看到已停用

每个服务器最多建立 10 张表单

## 删除

<SlashCommand name="form delete" description="选择表单，按确认按钮删除" />

删除前会再确认一次。删掉的表单会从列表消失，发布过的面板按钮随之失效；已开的子区不受影响，还没结案的仍然可以结案

## 处理回复

面板频道底下会多一个私密子区，名字像 `#0042 阿猫`

编号按提交顺序排，扫一眼子区列表就知道有几张单

机器龙会在子区里提及填表的人和通知身份组，并把答案整理成一张卡

多位管理员一起看单时，先按「接手」，卡片会显示由谁处理中。同一个人可以按「不再处理」交回，别人按「接手」只会看到已由谁接下

谈完后按「结案」，会弹出窗口让你选「通过」或「不通过」，并可以写一段给申请人的话（选填）。结果和那段话会留在卡片上，子区跟着归档并锁定

机器龙会在子区里提及申请人，告诉他申请通过或未通过，并附上那段话

只有通知身份组的成员，或有「管理子区」权限的人可以接手和结案

子区闲置七天会被 Discord 自动归档，这时单子也会自动结案。管理员直接归档子区也算结案

## 导出逐字稿

<SlashCommand
  name="form transcript"
  description="选一张申请，把子区导出成 Markdown 文件"
/>

导出的是一份 Markdown 文件，只有你看得到。消息原样保留，附件是连回 Discord 的链接

子区归档后也能导，超过 1000 条只保留最新的部分。菜单可以用表单名或编号搜索

## 封锁成员

有人反复开单闹场时：

| 指令 | 用途 |
| ---- | ---- |
| <Cmd name="form ban" /> | 封锁成员，他按任何表单按钮都会被拦下 |
| <Cmd name="form unban" /> | 解除封锁 |
| <Cmd name="form bans" /> | 看封锁名单 |

封锁名单每人一行，写明封锁时间和是谁封锁的，旁边有「解除封锁」按钮。人多时可以用「上一页」「下一页」翻页

封锁是整个服务器一起算，不分表单。已经开着的单不受影响，照常处理
