<Cmd name="form" /> 用来建立举报、申请或客服表单

成员从面板填完表单后，机器龙会开一个私密子区，把填表的人和管理员加入子区

## 创建

<SlashCommand name="form create" description="弹出表单，填标题和通知对象" />

填完基本资料后，机器龙会发一张只有你看得到的管理卡

| 字段 | 说明 |
| ---- | ---- |
| 标题 | 最多 45 字，也是成员填表窗口的标题 |
| 说明 | 选填，会显示在面板消息上 |
| 按钮文字 | 选填，不填就叫「填写」 |
| 通知身份组 | 1 到 5 个，有人提交表单时会提及他们。选 @everyone 的话，机器龙需要「提及所有人」权限才叫得动 |

## 编辑题目

用管理卡新增或删除题目，也可以随时用 <Cmd name="form edit" /> 选一张已有表单，重新打开管理卡

Discord 的表单窗口最多 5 题

题目分三种：

| 类型 | 说明 |
| ---- | ---- |
| 短答 | 一行文字 |
| 段落 | 多行文字，适合「请描述发生什么事」这种题目 |
| 单选 | 下拉菜单，选项填 2 到 25 个，用逗号或换行分隔 |

已发布的表单仍可改题目，成员下次点面板时会看到最新版本

## 发布

<SlashCommand name="form send" description="选择表单和文字频道，发布填写面板" />

同一张表单可以发到多个文字频道

## 暂停与恢复

| 命令 | 用途 |
| ---- | ---- |
| <Cmd name="form disable" /> | 暂停接受新回复，已有面板会保留 |
| <Cmd name="form enable" /> | 恢复接受新回复 |

每个服务器最多建立 10 张表单

## 删除

<SlashCommand name="form delete" description="选择表单，按确认按钮删除" />

删除前会再确认一次。删掉的表单会从列表消失，发布过的面板按钮随之失效；已开的子区不受影响，还没结案的仍然可以结案

## 处理回复

面板频道底下会多一个私密子区，名字像 `#0042 阿猫`

编号按提交顺序排，扫一眼子区列表就知道有几张单

机器龙会在子区里提及填表的人和通知身份组，并把答案整理成一张卡

谈完后按「结案」，子区会归档并锁定

只有通知身份组的成员，或有「管理子区」权限的人可以结案
