---
title: 鎖定語音頻道
description: 幫語音頻道上密碼，輸入正確密碼的成員才能進入。
---

<Cmd name="lock-channel" /> 幫語音頻道上密碼，適合開小團體討論又不想另外設定權限的時候。上鎖需要 **管理頻道** 權限，加入則是任何成員都可以。

<CommandHeader you={["管理頻道"]} bot={["管理頻道", "管理身分組"]} />

<LockChannelDemo />

## 上鎖

<SlashCommand
  name="lock-channel setup"
  options={[
    { name: "channel", value: "#幹部頻道", required: true },
    { name: "password", value: "••••••", required: true },
  ]}
  description="幫語音頻道設定密碼"
/>

上鎖後成員會進不去這個頻道，要輸入密碼才能加入。

回覆會列出受影響的身分組：原本能進這個頻道的身分組，之後也要輸入密碼。解除鎖定時會還原。

回覆底下有兩顆按鈕：

| 按鈕 | 作用 |
| ---- | ---- |
| 貼出按鈕 | 在頻道貼一則訊息，成員按「輸入密碼」就能加入，不用記指令 |
| 移除鎖定 | 馬上解除鎖定 |

## 加入

成員有兩種加入方式。按訊息上的「輸入密碼」，在視窗填密碼；或用 `join` 指令。

<SlashCommand
  name="lock-channel join"
  options={[
    { name: "channel", value: "#幹部頻道", required: true },
    { name: "password", value: "••••••", required: true },
  ]}
  description="輸入密碼獲得進入權限"
/>

密碼正確就會獲得該頻道的進入權限，直接點進頻道就能加入。

密碼錯誤時，回覆會告訴你還能再試幾次。錯滿次數後要等一陣子才能再試。

## 管理

| 指令 | 說明 |
| ---- | ---- |
| <Cmd name="lock-channel change" /> | 更換密碼 |
| <Cmd name="lock-channel remove" /> | 解除鎖定 |

換密碼時，回覆會附「收回權限」按鈕。按下去，用舊密碼加入的成員要輸入新密碼才能再進來。目前在頻道裡的人不會被踢出。頻道擁有者和有 **管理頻道** 權限的人不受影響。

解除鎖定只會還原機器龍改過的權限，其他權限不動。

<Callout>
  密碼由設定的人管理，有 **管理頻道** 權限的成員也能更換或解除。
</Callout>
