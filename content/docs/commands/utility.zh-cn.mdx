## 图片卡片

这些命令会返回图片卡片：

| 命令 | 说明 |
| ---- | ---- |
| <Cmd name="quote" /> | 把某人最近的消息做成名言图片 |
| <Cmd name="fortune" /> | 抽今天的签诗，同一天的结果相同 |
| <Cmd name="compat" /> | 看两位成员的相性 |
| <Cmd name="fake" /> | 把文字做成新闻、聊天截图、搜索结果或感谢状 |

<Cmd name="fortune" /> 的签诗会印上抽签的人，下面有「我也抽」按钮，其他人点了就能抽自己的。

<Cmd name="compat" /> 的图片上方写着两个人的名字和分数。结果不会通知被算的那个人。

<Cmd name="fake" /> 做好后先给你私人预览。点「分享」才会发到频道，图片下方会注明是你做的。超过字数上限的部分会被截掉，预览会告诉你。

<Cmd name="quote" /> 也能从右键菜单使用

对消息点右键，手机则长按，选「应用」后再选 **quote-message**

用命令引用时，机器龙只会找对方最近 100 条消息。找不到的话，回复会说明这个范围，并教你改用右键菜单引用更早的消息

## 查询

| 命令 | 说明 |
| ---- | ---- |
| <Cmd name="status" /> | 机器龙状态：延迟、服务器数、账号安装数、运行时间 |
| <Cmd name="guild" /> | 当前服务器的信息：成员数、所有者、创建日期和加成等级 |
| <Cmd name="avatar" /> | 获取用户头像原图（2048px），默认显示服务器头像 |
| <Cmd name="banner" /> | 获取用户横幅原图 |
| <Cmd name="minecraft player" /> | Minecraft 玩家信息，可绑定自己的 ID |
| <Cmd name="minecraft server" /> | Minecraft 服务器状态，显示在线人数 |

<Cmd name="avatar" /> 的对象有设置服务器头像时，默认显示那一张。下面的按钮可以切换成个人头像，或打开原图。

<Cmd name="minecraft player" /> 还没绑定时，回复会说明怎么绑：在命令填入玩家名称，再点「绑定账号」。绑定后不填名称就会查自己。

<Cmd name="minecraft server" /> 的结果可以点「重新查询」更新。

## 娱乐

| 命令 | 说明 |
| ---- | ---- |
| <Cmd name="pick" /> | 丢一个问题，机器龙帮你选答案，回复会先引用你的问题 |
| <Cmd name="random number" /> | 抽一个范围内的整数 |
| <Cmd name="random voice-channel" /> | 从语音频道随机抽一位成员 |
| <Cmd name="1a2b" /> | 1A2B 猜数字，5 种难度 |
| <Cmd name="bullshit" /> | 道歉文、情书生成器，可指定字数 |

<Cmd name="1a2b" /> 的每次猜测都在同一条消息里更新，并列出完整的猜测记录。

<SlashCommand
  name="bullshit"
  options={[
    { name: "topic", value: "迟到的道歉文", required: true },
    { name: "length", value: "500" },
  ]}
  description="生成一篇 500 字的文章，超过 1500 字会用文本文件附上"
/>

`topic` 最多 50 字。生成后先给你私人预览，下面有两个按钮：

| 按钮 | 作用 |
| ---- | ---- |
| 换一篇 | 用同一个主题重写一篇 |
| 分享 | 发到频道，并注明作者是你 |

文章太长时，会改成文本文件附上，分享出去的也是那份文件。

## 服务器与账号

| 命令 | 说明 |
| ---- | ---- |
| <Cmd name="language" /> | 设置机器龙在这个服务器用的语言，需要 **管理服务器** 权限 |
| <Cmd name="afk-channel" /> | 让机器龙一直待在某个语音频道，需要 **管理服务器** 权限 |
| <Cmd name="delete-data" /> | 删除你存在机器龙这里的数据 |
| <Cmd name="help" /> | 看机器龙有哪些命令 |

### 语言

<Cmd name="language" /> 不带选项时，会显示当前的设置：用哪种语言，或是跟随每个人的 Discord 语言。选「跟随 Discord」会回到各自的语言设置。

### 待命频道

`afk-channel` 有三个子命令：

| 子命令 | 说明 |
| ---- | ---- |
| `set` | 让机器龙待在指定的语音频道。设置前会检查机器龙在那个频道有没有「连接」权限 |
| `show` | 看机器龙当前待在哪个频道 |
| `clear` | 让机器龙离开 |

这个频道和 Discord 服务器设置里的 AFK 频道无关。

### 删除数据

<SlashCommand name="delete-data" description="删除你存在机器龙这里的数据" />

机器龙会先列出各类数据各有多少条：账号绑定、游戏数据和旧时代数据。选好要删的类别后，点「删除」就会执行，不需要再输入文字。

删除后数据会保留 30 天备份，只用来救回误删。需要的话，到支持服务器申请。投票、表单、抽奖这类服务器共用的记录不会删除。

### 帮助

<SlashCommand name="help" description="打开帮助面板" />

面板只有你看得到。首页列出大多数服务器常用的命令，下拉菜单可以按分类查看：管理与防护、迎新与身分组、语音频道、活动、小游戏与趣味、小工具，以及机器龙本身。

「这个服务器的设置」页会列出当前开启的功能，例如陷阱频道、动态语音频道和新成员身份组，以及哪些功能出了问题。只有 **管理服务器** 权限的人看得到这一页。

面板下面有使用说明、邀请和支持群组的链接。
