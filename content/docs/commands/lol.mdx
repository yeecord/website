<Cmd name="lol" /> 查詢英雄聯盟的玩家資訊，戰績卡片會畫成圖片。

目前只查得到台港澳伺服器的玩家。查其他伺服器的玩家時，機器龍會告訴你查不到的原因。

Riot 暫時沒有回應時，回覆會附「重試」按鈕，按下去用同樣的條件再查一次。

<CommandHeader />

## 綁定帳號

<SlashCommand
  name="lol link"
  options={[{ name: "name", value: "Hide on bush#KR1", required: true }]}
  description="綁定你的 Riot ID，格式是 名稱#Tag"
/>

綁定結果只有你看得到。

重新綁定時，回覆會告訴你取代了哪個帳號。

綁定後其他子指令的 `name` 都可以留空，直接查自己。還沒綁定時，回覆會附「綁定帳號」按鈕，按下去填 Riot ID 就能綁。

## 查詢

| 指令 | 說明 |
| ---- | ---- |
| <Cmd name="lol player" /> | 玩家卡片：第一行是牌位，附單雙排／彈性積分和英雄專精，底下有「近期戰績」「即時戰局」按鈕 |
| <Cmd name="lol matches" /> | 最近 10 場戰績，只有你看得到 |
| <Cmd name="lol live" /> | 正在進行的對局 |
| <Cmd name="lol rotation" /> | 本週免費輪替英雄，依英雄分類列出 |

## 近期戰績

<Cmd name="lol matches" /> 會列出最近 10 場。從選單選一場，就能看完整的對戰卡。

對戰卡預設只有你看得到。按「分享這場」才會發到頻道，頻道裡只會看到這一場的對戰卡。

## 即時戰局

<Cmd name="lol live" /> 顯示佇列類型、開打時間，以及雙方每位玩家的英雄和 Riot ID。

局勢會一直變，按「重新整理」更新。玩家沒在遊戲裡時，會告訴你對方上一場什麼時候結束。
