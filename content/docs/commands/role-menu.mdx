## 建立選單

<SlashCommand name="role-menu" description="傳送一則自助領取身分組的訊息" />

需要 **管理身分組** 權限。執行後會跳出表單：

| 欄位 | 說明 |
| ---- | ---- |
| 發佈到哪個頻道 | 選單要發到哪裡。必須是你自己看得到、也能發言的頻道 |
| 樣式 | 按鈕，或一顆「選身分組」按鈕（按下去開個人選單） |
| 每人可以選 | 「不限」，或「只能選一個」 |
| 內文 | 最多 4000 字，支援 Markdown |
| 身分組 | 最多 25 個 |

<RoleMenuDemo />

選「只能選一個」時，成員選了新的身分組，會自動換掉原本的那個。

## 領取身分組

按鈕型的選單，成員點按鈕獲得身分組，再點一次取消。

選「選身分組」型的選單，成員按下按鈕後，會看到只有自己看得到的選單。勾選想要的身分組，送出就會更新。

領到或移除後，回覆會附「復原」按鈕，按錯了可以馬上還原。

## 編輯選單

管理員按選單上的「編輯選單」，就能修改內文、身分組和每人可選的數量。成員看到的會是新的內容。

## 可以發出的身分組

<Callout type="warn">
  要發的身分組必須排在機器龍最高身分組的下面，不然機器龍沒有權限給予，
  詳見 [身分組順序的調整教學](../basics.mdx#身分組的順序很重要)。
</Callout>

選單不能發出帶有下列任一權限的身分組：

- 管理員
- 管理伺服器
- 管理身分組
- 管理頻道
- 管理 Webhook
- 封鎖成員
- 踢出成員
- 禁言成員
- 管理訊息
- 提及所有人

選到這類身分組時，機器龍會告訴你是哪個身分組、帶有什麼權限，請你改選其他的。

## 想改成自動發放？
