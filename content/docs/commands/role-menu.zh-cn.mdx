## 创建菜单

<SlashCommand name="role-menu" description="发送一条自助领取身份组的消息" />

需要 **管理身份组** 权限。执行后会弹出表单：

| 字段 | 说明 |
| ---- | ---- |
| 发布到哪个频道 | 菜单要发到哪里。必须是你自己看得到、也能发言的频道 |
| 样式 | 按钮，或一个“选身份组”按钮（点下去打开个人菜单） |
| 每人可以选 | 「不限」，或「只能选一个」 |
| 内文 | 最多 4000 字，支持 Markdown |
| 身份组 | 最多 25 个 |

<RoleMenuDemo />

选「只能选一个」时，成员选了新的身份组，会自动换掉原本的那个。

## 领取身份组

按钮型的菜单，成员点按钮获得身份组，再点一次取消。

选「选身份组」型的菜单，成员点下按钮后，会看到只有自己看得到的菜单。勾选想要的身份组，提交就会更新。

领到或移除后，回复会附「撤销」按钮，点错了可以马上还原。

## 编辑菜单

管理员点菜单上的「编辑选单」，就能修改内文、身份组和每人可选的数量。成员看到的会是新的内容。

## 可以发出的身份组

<Callout type="warn">
  要发的身份组必须排在机器龙最高身份组的下面，不然机器龙没有权限给予，
  详见 [身份组顺序的调整教程](../basics.mdx#身份组的顺序很重要)。
</Callout>

菜单不能发出带有下列任一权限的身份组：

- 管理员
- 管理服务器
- 管理身份组
- 管理频道
- 管理Webhook
- 封禁成员
- 踢出成员
- 禁言成员
- 管理消息
- 提及所有人

选到这类身份组时，机器龙会告诉你是哪个身份组、带有什么权限，请你改选其他的。

## 想改成自动发放？

新成员一进来就该有的身份组，用 [新成员身份组](./auto-role.mdx) 自动发。
