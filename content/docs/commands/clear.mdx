<Cmd name="clear" /> 大量刪除頻道訊息。刪除任務會排進佇列在背景執行，就算要刪 1000 則也不用等它跑完。

<CommandHeader you={["管理訊息"]} bot={["管理訊息", "閱讀歷史訊息"]} />

## 新增刪除任務

<SlashCommand
  name="clear add"
  options={[
    { name: "amount", value: "100", required: true },
    { name: "user", value: "@某人" },
  ]}
  description="刪除這個頻道最近的 100 則訊息，加 user 參數就只刪他的"
/>

| 參數 | 必填 | 說明 |
| ---- | ---- | ---- |
| `amount` | ✅ | 要刪的數量，1 到 1000 |
| `user` | | 只刪這位成員的訊息 |
| `authors` | | 只刪機器人、或只刪真人的訊息 |
| `contains` | | 只刪內文包含這段文字的訊息，不分大小寫 |
| `with` | | 只刪帶連結、或帶附件的訊息 |

篩選條件可以疊加，全部成立才會刪。釘選訊息一律跳過，不用擔心公告被清掉。超過 14 天的訊息 Discord 不允許大量刪除，也會跳過。

要刪超過 100 則時，機器龍會先問你確認。確認畫面列出頻道、範圍和篩選條件，按「刪除 N 則訊息」才會開始。刪掉的訊息無法復原。

開始後，進度會在同一則只有你看得到的訊息裡更新。想中途停下，按「停止」。已刪除的訊息不會恢復，沒刪的會保留。

任務結束後，頻道會收到一則通知。如果實際刪除的數量比設定的少，通知會說明可能的原因。

## 中斷後繼續

機器龍失去頻道的「管理訊息」權限，或任務被中斷時，通知會寫出已刪除幾則。補上權限後，按「繼續刪除」就能接著刪剩下的。

## 管理佇列

| 指令 | 說明 |
| ---- | ---- |
| <Cmd name="clear list" /> | 查看進行中和排隊中的任務，包含剩餘數量，每筆寫明是誰新增的。進行中的任務旁有「停止」，排隊中的有「取消」，可以只處理那一個。底下有「全部停止」 |
| <Cmd name="clear flush" /> | 停止伺服器裡所有還沒跑完的任務，包括其他管理員排的。會先請你確認，按下「停止 N 筆任務」才會執行 |

停止、取消和繼續刪除，都需要你在那個頻道有 **管理訊息** 權限。沒有的話，機器龍會請管理員在該頻道開啟後再試一次。
