<Cmd name="member-notification" /> 设置成员加入、退出服务器时的通知消息。

<CommandHeader you={["管理服务器"]} />

## 设置

<SlashCommand
  name="member-notification"
  options={[{ name: "type", value: "join", required: true }]}
  description="type 选填。不填会打开状态面板，选 join 或 leave 直接设置那一种通知"
/>

不带选项时，会打开只有你看得到的状态面板，一次看到加入通知和退出通知的状态：

| 状态 | 面板上的按钮 |
| ---- | ------------ |
| 还没设置 | 设置 |
| 开启中 | 编辑、停用 |
| 已停用 | 编辑、开启。内文与图卡都还留着，点「开启」就能恢复 |
| 频道失效而自动停用 | 编辑、重新启用。面板会写出原因 |

点「设置」或「编辑」会弹出表单。「编辑」会带入旧值，只改想改的地方就好：

| 字段 | 说明 |
| ---- | ---- |
| 频道 | 通知要发到哪个文字频道 |
| 通知内文 | 最多 2000 字，支持 Markdown |
| 图卡 | 不出图卡，或选一种样式附在通知下面 |

消息内容里可以放变量：

| 变量 | 发送时换成 |
| ---- | ---- |
| `{user}` | 成员名称，纯文本 |
| `{mention}` | 标注成员，对方会收到通知 |

<DiscordChat>
  <DiscordMessage>
    <p>欢迎 <Mention>@新成员</Mention> 加入服务器！先到规则频道看看吧 🎉</p>
  </DiscordMessage>
</DiscordChat>

保存后通知会开启，机器龙会用你本人代入变量，回一条只有你看得到的预览，不用等真的有人进来才能确认。

## 图卡

选了图卡样式，通知文字下面会多一张图：成员头像、名字、服务器名，加入时写第几位成员，退出时写现有人数。

| 样式 | 长相 |
| ---- | ---- |
| 招牌 | 大头像在左，名字当招牌字，红色「欢迎光临」标签 |
| 入场券 | 左边红色票根印「入场券 No. 1234」，虚线撕边，右边是成员资料 |
| 印章 | 居中版面，名字下面盖一颗红印「欢迎」 |

退出通知用同一套样式，字会换成道别的版本。图卡的文字跟着服务器的语言设置走。

想关掉就重跑命令，图卡选「不出图卡」。

加入和退出的消息分开设置，各跑一次命令就好。

## 用频道消息当模板

提及、表情、换行在频道的输入框里打比在表单里顺手。先在任一频道把通知打好、发送，再对那条消息右键 → Apps →「设为模板」。

会弹出同一张设置表单，内文已经填好，多一个「用途」字段选加入通知或退出通知。打完的那条消息可以自己删掉。

<Callout type="warn">
  发送频道被删掉、或机器龙无法在那个频道发消息的时候，通知会自动停用，状态面板会写出原因和是从什么时候开始的。频道被删了就点「编辑」换一个；还在的话，到频道权限把机器龙这两项打开，再点「重新启用」：

  <ChannelPermissionDemo
    title="频道设置 → 权限 → YEE式机器龙"
    permissions={[
      { name: "查看频道", enabled: true },
      { name: "发送消息", enabled: true },
    ]}
    caption="两个都开，机器龙才能在这个频道发通知"
  />
</Callout>
