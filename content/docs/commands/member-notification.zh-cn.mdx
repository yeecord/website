<Cmd name="member-notification" /> 设置成员加入、退出服务器时的通知消息。

<CommandHeader you={["管理服务器"]} />

## 设置

<SlashCommand
  name="member-notification"
  options={[{ name: "type", value: "join", required: true }]}
  description="type 选填。不填会打开状态面板，选 join 或 leave 直接设置那一种通知"
/>

不带选项时，会打开只有你看得到的状态面板，一次看到加入通知和退出通知的状态：

| 状态 | 面板上的按钮 |
| ---- | ------------ |
| 还没设置 | 设置 |
| 开启中 | 编辑、停用 |
| 已停用 | 编辑、开启。内文与图卡都还留着，点「开启」就能恢复 |
| 频道失效而自动停用 | 编辑、重新启用。面板会写出原因 |

点「设置」或「编辑」会弹出表单。「编辑」会带入旧值，只改想改的地方就好：

| 字段 | 说明 |
| ---- | ---- |
| 频道 | 通知要发到哪个文字频道 |
| 通知内文 | 最多 2000 字，支持 Markdown |
| 图卡 | 不出图卡，或选一种样式附在通知下面 |

消息内容里可以放变量，状态面板下方也会列出来：

| 变量 | 发送时换成 |
| ---- | ---- |
| `{user.name}` | 成员的显示名称，没设就是用户名 |
| `{user.username}` | 用户名 |
| `{user.id}` | 用户 ID |
| `{user.mention}` | 标注成员，对方会收到通知 |
| `{user.avatar}` | 头像链接 |
| `{user.bot}` | 是不是机器人 |
| `{user.created}` | 账号创建时间 |
| `{member.nick}` | 服务器昵称，没设就是空的 |
| `{member.display}` | 服务器昵称，没设就是显示名称 |
| `{member.joined}` | 加入服务器的时间 |
| `{server.name}` | 服务器名称 |
| `{server.id}` | 服务器 ID |
| `{server.icon}` | 服务器图标链接 |
| `{server.member_count}` | 目前的成员人数 |
| `{time.now}` | 发送的时间 |

成员离开后就没有 `{member.nick}` 和 `{member.joined}`，离开通知用了它们会保存不了。

时间默认显示成每个人自己时区的完整日期时间，`{user.created}` 则是「3 年前」这种相对时间。在后面加 `:` 和一个字母可以换格式，例如 `{member.joined:R}`：

| 字母 | 样子 |
| ---- | ---- |
| `t` | 20:30 |
| `T` | 20:30:00 |
| `d` | 2026/11/08 |
| `D` | 2026年11月8日 |
| `f` | 2026年11月8日 20:30 |
| `F` | 2026年11月8日星期日 20:30 |
| `R` | 3 年前 |

`{server.member_count:ordinal}` 会写成序数，中文是「第 1,234」，英文是「1,234th」。

另外有两个随机的写法：

| 写法 | 发送时换成 |
| ---- | ---- |
| `{choose:早安\|午安\|晚安}` | 用 `\|` 隔开的其中一个，每次随机 |
| `{range:1-6}` | 1 到 6 之间的整数，每次随机 |

想打出大括号本身就写 `\{`。机器龙不认识的名字会按原样显示，保存时会提醒你，打错字的话还会猜你想打哪一个。

旧的 `{user}`、`{mention}`、`{server}`、`{member_count}` 还能用，分别等于 `{member.display}`、`{user.mention}`、`{server.name}`、`{server.member_count}`。

## 图卡

选了图卡样式，通知文字下面会多一张图：成员头像、名字、服务器名，加入时写第几位成员，退出时写现有人数。

| 样式 | 长相 |
| ---- | ---- |
| 招牌 | 大头像在左，名字当招牌字，红色「欢迎光临」标签 |
| 入场券 | 左边红色票根印「入场券 No. 1234」，虚线撕边，右边是成员资料 |
| 印章 | 居中版面，名字下面盖一颗红印「欢迎」 |

退出通知用同一套样式，字会换成道别的版本。图卡的文字跟着服务器的语言设置走。

想关掉就重跑命令，图卡选「不出图卡」。

加入和退出的消息分开设置，各跑一次命令就好。

## 用频道消息当模板

提及、表情、换行在频道的输入框里打比在表单里顺手。先在任一频道把通知打好、发送，再对那条消息右键 → Apps →「设为模板」。

会弹出同一张设置表单，内文已经填好，多一个「用途」字段选加入通知或退出通知。打完的那条消息可以自己删掉。

<Callout type="warn">
  发送频道被删掉、或机器龙无法在那个频道发消息的时候，通知会自动停用，状态面板会写出原因和是从什么时候开始的。频道被删了就点「编辑」换一个；还在的话，到频道权限把机器龙这两项打开，再点「重新启用」：

  <ChannelPermissionDemo
    title="频道设置 → 权限 → YEE式机器龙"
    permissions={[
      { name: "查看频道", enabled: true },
      { name: "发送消息", enabled: true },
    ]}
    caption="两个都开，机器龙才能在这个频道发通知"
  />
</Callout>
