---
title: 锁定语音频道
description: 给语音频道上密码，输入正确密码的成员才能进入。
---

<Cmd name="lock-channel" /> 给语音频道上密码，适合开小团体讨论又不想另外设置权限的时候。上锁需要 **管理频道** 权限，加入则是任何成员都可以。

<CommandHeader you={["管理频道"]} bot={["管理频道", "管理身份组"]} />

<LockChannelDemo />

## 上锁

<SlashCommand
  name="lock-channel setup"
  options={[
    { name: "channel", value: "#干部频道", required: true },
    { name: "password", value: "••••••", required: true },
  ]}
  description="给语音频道设置密码"
/>

上锁后成员会进不去这个频道，要输入密码才能加入。

回复会列出受影响的身份组：原本能进这个频道的身份组，之后也要输入密码。解除锁定时会还原。

回复下面有两个按钮：

| 按钮 | 作用 |
| ---- | ---- |
| 发出按钮 | 在频道发一条消息，成员点「输入密码」就能加入，不用记命令 |
| 移除锁定 | 马上解除锁定 |

## 加入

成员有两种加入方式。点消息上的「输入密码」，在窗口填密码；或用 `join` 命令。

<SlashCommand
  name="lock-channel join"
  options={[
    { name: "channel", value: "#干部频道", required: true },
    { name: "password", value: "••••••", required: true },
  ]}
  description="输入密码获得进入权限"
/>

密码正确就会获得该频道的进入权限，直接点进频道就能加入。

密码错误时，回复会告诉你还能再试几次。错满次数后要等一阵子才能再试。

## 管理

| 命令 | 说明 |
| ---- | ---- |
| <Cmd name="lock-channel change" /> | 更换密码 |
| <Cmd name="lock-channel remove" /> | 解除锁定 |

换密码时，回复会附「收回 N 位成员的权限」按钮。点下去，用旧密码加入的成员要输入新密码才能再进来。当前在频道里的人不会被踢出。频道所有者和有 **管理频道** 权限的人不受影响。

解除锁定只会还原机器龙改过的权限，其他权限不动。

<Callout>
  密码由设置的人管理，有 **管理频道** 权限的成员也能更换或解除。
</Callout>
