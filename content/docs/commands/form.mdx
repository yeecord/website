## 建立

<SlashCommand name="form create" description="跳出表單，填標題和通知對象" />

填完基本資料後，機器龍會傳一張只有你看得到的管理卡

| 欄位 | 說明 |
| ---- | ---- |
| 標題 | 最多 45 字，也是成員填表視窗的標題 |
| 說明 | 選填，會顯示在面板訊息上 |
| 按鈕文字 | 選填，不填就叫「填寫」 |
| 通知身分組 | 1 到 5 個，有人送出表單時會標註他們。身分組要開「允許任何人提及這個身分組」才會收到通知，不然只會顯示標註、不會響 |

## 編輯題目

用管理卡新增或刪除題目，也可以隨時用 <Cmd name="form edit" /> 選一張既有表單，重新開啟管理卡

Discord 的表單視窗最多 5 題

題目分三種：

| 類型 | 說明 |
| ---- | ---- |
| 短答 | 一行文字 |
| 段落 | 多行文字，適合「請描述發生什麼事」這種題目 |
| 單選 | 下拉選單，選項填 2 到 25 個，用逗號或換行分隔 |

已發佈的表單仍可改題目，成員下次點面板時會看到最新版本

## 發佈

<SlashCommand name="form send" description="選擇表單和文字頻道，發佈填寫面板" />

同一張表單可以發到多個文字頻道

## 暫停與恢復

| 指令 | 用途 |
| ---- | ---- |
| <Cmd name="form disable" /> | 暫停接受新回覆，既有面板會保留 |
| <Cmd name="form enable" /> | 恢復接受新回覆 |

每個伺服器最多建立 10 張表單

## 刪除

<SlashCommand name="form delete" description="選擇表單，按確認按鈕刪除" />

刪除前會再確認一次。刪掉的表單會從列表消失，發佈過的面板按鈕跟著失效；已開的討論串不受影響，還沒結案的仍然可以結案

## 處理回覆

面板頻道底下會多一個私人討論串，名字像 `#0042 阿貓`

編號照送出順序排，掃一眼討論串列表就知道有幾張單

機器龍會在討論串裡標註填表的人和通知身分組，並把答案整理成一張卡

多位管理員一起顧單時，先按「接單」，卡片會顯示由誰處理中。同一個人再按一次就交回，別人按只會看到已由誰接下

談完後按「結案」，會跳出視窗讓你填關閉理由（可以不填），關閉人和理由會留在卡片上，討論串跟著封存並上鎖

只有通知身分組的成員，或有「管理討論串」權限的人可以接單和結案

## 匯出逐字稿

<SlashCommand
  name="form transcript"
  description="選一張申請，把討論串匯出成 Markdown 和 JSON"
/>

匯出的兩份檔案只有你看得到。Markdown 那份給人讀，訊息原樣保留，附件是連回 Discord 的連結。JSON 那份給程式讀，多帶訊息編號、送出者編號和時間

討論串封存後也能匯，超過 1000 則只保留最新的部分。選單可以用表單名或編號搜尋
