title: 动态语音频道
description: 一个频道满足所有人的语音需求，成员加入时自动生成专属频道，没人用就自动回收。
---

为了不同用途开一堆语音频道，像是 `游戏用`、`听歌用`，频道一多列表就会很乱。

动态语音频道只需要一个「大厅」：成员加入时，机器龙自动开一间专属于他的「房间」并把他移过去；房间没人之后自动删除。

## 安装

<SlashCommand
  name="auto-channels setup"
  options={[{ name: "channel", value: "#创建频道", required: true }]}
  description="把一个语音频道设为大厅"
/>

选一个现有的语音频道当大厅就完成了。每个服务器最多设 2 个大厅，房间不能再被设为大厅。

结果只有你看得到。对已经是大厅的频道再跑一次 `setup`，房间名称、人数上限和音质会保持原样。

## 房主权限

开房的人自动拿到自己房间的「管理频道」和「移动成员」权限，可以直接用 Discord 界面改名、设人数上限、把人踢出语音。权限只在这个房间有效，房间删除就跟着消失。

## 保留房间

房间默认没人就删。想留下某个房间（例如已经布置好权限的），用：

<SlashCommand
  name="auto-channels keep"
  options={[{ name: "channel", value: "#开黑频道", required: true }]}
  description="让这个房间不会被自动删除"
/>

结果只有你看得到。只能保留大厅开出来的房间。

## 查看列表

<SlashCommand
  name="auto-channels list"
  description="打开大厅面板"
/>

面板只有你看得到，列出服务器里所有大厅，以及各自当前的房间。每个大厅旁有两个按钮：

| 按钮 | 作用 |
| ---- | ---- |
| 设置 | 修改房间名称、人数上限和音质 |
| 卸载 | 把这个频道移出大厅 |

房间名称里的 `%user%` 会换成成员名称。人数上限填 0 代表不限，最多 99 人。音质可选标准或最高。

大厅缺少权限时，面板会告诉你机器龙还需要开哪些权限。

## 卸载

<SlashCommand
  name="auto-channels remove"
  options={[{ name: "channel", value: "#创建频道", required: true }]}
  description="卸载大厅"
/>

也可以在大厅面板点“卸载”。

机器龙会先确认。当前有房间时，你可以选：

| 按钮 | 结果 |
| ---- | ---- |
| 删除房间 | 房间一并删除，里面的人会断线 |
| 保留房间 | 房间改为普通语音频道 |

大厅频道本身不会被删除。
