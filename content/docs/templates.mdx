---
title: 範本
description: 成員通知的內文和動態語音的房間名稱都能放變數，發送時換成實際的成員、伺服器和時間。
---

成員通知的內文和[動態語音](./commands/auto-channels.mdx)的房間名稱都是範本。範本裡用大括號寫變數，機器龍發送時會換成實際的值。例如這段加入通知：

```txt
歡迎 {user.mention} 加入 {server.name}，你是第 {server.member_count:ordinal} 位成員！
```

有人加入時會變成：

<DiscordChat>
  <DiscordMessage>
    <p>歡迎 <Mention>@新成員</Mention> 加入 YEE 式伺服器，你是第 1,234 位成員！</p>
  </DiscordMessage>
</DiscordChat>

## 查看能用的變數

成員通知的狀態面板和動態語音的大廳面板上都有一顆「範本變數」按鈕。按下去會打開一頁只有你看得到的清單，列出那個地方能用的每個變數，旁邊是用你自己代入的結果。清單最下面的「完整說明」會連回這一頁。

## 變數

變數寫成 `{種類.欄位}`，種類有使用者 `user`、伺服器成員 `member`、伺服器 `server` 和時間 `time`：

| 變數 | 發送時換成 |
| ---- | ---- |
| `{user.name}` | 成員的顯示名稱，沒設就是使用者名稱 |
| `{user.username}` | 使用者名稱 |
| `{user.id}` | 使用者 ID |
| `{user.mention}` | 標註成員，對方會收到通知 |
| `{user.avatar}` | 頭像網址 |
| `{user.bot}` | 是不是機器人 |
| `{user.created}` | 帳號建立時間 |
| `{member.nick}` | 伺服器暱稱，沒設就是空的 |
| `{member.display}` | 伺服器暱稱，沒設就是顯示名稱 |
| `{member.joined}` | 加入伺服器的時間 |
| `{server.name}` | 伺服器名稱 |
| `{server.id}` | 伺服器 ID |
| `{server.icon}` | 伺服器圖示網址 |
| `{server.member_count}` | 目前的成員人數 |
| `{time.now}` | 發送的時間 |

## 成員通知和房間名稱的差別

兩個地方能用的變數不完全一樣，因為頻道名稱只能放一行純文字：

| | 成員通知 | 房間名稱 |
| ---- | ---- | ---- |
| `{user.mention}` | 標註成員 | 不能用 |
| `{user.avatar}`、`{server.icon}` | 網址 | 不能用 |
| `{member.nick}`、`{member.joined}` | 加入通知能用，離開通知不能用 | 能用 |
| 時間 | 每個人自己時區的時間，可以換格式 | 依伺服器語言排列的日期，例如 2026/11/8 |
| 換行 | 保留 | 拿掉 |

成員離開後，機器龍就拿不到他在伺服器裡的暱稱和加入時間，所以離開通知不能用 `{member.nick}` 和 `{member.joined}`。

## 時間格式

成員通知裡的時間會顯示成每個人自己時區的完整日期時間，`{user.created}` 則是「3 年前」這種相對時間。在變數後面加 `:` 和一個字母可以換格式，例如 `{member.joined:R}`：

| 字母 | 樣子 |
| ---- | ---- |
| `t` | 下午 8:30 |
| `T` | 下午 8:30:00 |
| `d` | 2026/11/08 |
| `D` | 2026年11月8日 |
| `f` | 2026年11月8日 下午 8:30 |
| `F` | 2026年11月8日星期日 下午 8:30 |
| `R` | 3 年前 |

## 序數

`{server.member_count:ordinal}` 會把人數寫成序數，中文是「第 1,234」，英文是「1,234th」。

## 隨機

這兩個寫法每次發送都會重新抽：

| 寫法 | 發送時換成 |
| ---- | ---- |
| `{choose:早安\|午安\|晚安}` | 用 `\|` 隔開的其中一個，每次隨機 |
| `{range:1-6}` | 1 到 6 之間的整數，每次隨機 |

## 打出大括號

在大括號前面加反斜線就會照字面顯示，例如 `\{user.name}` 會顯示成 `{user.name}`。

## 存檔時的檢查

存檔前機器龍會先讀過範本：

- 用了這個地方拿不到的變數，例如在離開通知用 `{member.joined}`，或在房間名稱用 `{user.mention}`，設定不會變更。
- 機器龍不認得的名字會照原樣顯示。存檔會成功，但機器龍會提醒你，打錯字的話還會猜你想打哪一個。
- 一個範本最多放 50 個變數。

## 舊的寫法

舊的 `{user}`、`{mention}`、`{server}`、`{member_count}` 還能用，分別等於 `{member.display}`、`{user.mention}`、`{server.name}`、`{server.member_count}`。已經存好的範本不用改。
