## 覓食

選一個地點出門後，袋子會隨時間裝滿

大約一天半到兩天後回來收成，才會知道這趟帶回什麼

- 食材有普通、稀有、傳說三種稀有度
- 每個地點每天輪換情報，提示今天容易撿到什麼
- 有保底機制：連續幾次沒遇到新食材，之後幾次內必定遇到
- 偶爾會撿到驚喜，也會看到其他玩家最近的收穫足跡
- 路上會碰到小事件，選不同的分支有不同結果

## 烹飪

從背包挑幾樣食材下鍋，Yee 會評分：

| 評級 | 說明 |
| ---- | ---- |
| 普通 | 能吃 |
| 好吃 | 食材搭配得不錯 |
| 絕品 | 完美組合 |

食材搭配不對會煮出黑暗料理

黑暗料理也有自己的隱藏菜譜

每天有一個「今日想吃」的風味提示，只給方向不給答案，照著方向煮容易拿高分。

## 菜譜與餵養

- 菜譜會記錄你煮過的料理
- 餵 Yee 可以累積感情，解鎖更多互動
- 分享成績會產生一張卡片

## 銅板

覓食和烹飪會獲得銅板

銅板只在遊戲內使用，不能和其他玩家交易

- 在 [top.gg 投票](https://top.gg/bot/584213384409382953/vote) 也會獲得銅板
- 每 12 小時可以投一次，週末一票算兩票
- 獎勵會直接存進錢包
