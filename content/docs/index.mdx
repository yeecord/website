## 兩種安裝方式

| 安裝方式 | 說明 |
| -------- | ---- |
| 加入伺服器 | 整個伺服器的成員都能使用 |
| 安裝到帳號 | 裝在你自己的 Discord 帳號上，私訊、群組私訊、任何伺服器都能用 |

Discord 會在安裝時讓你選擇，兩種方式可以同時使用。安裝到帳號後，<Cmd name="poll" />、<Cmd name="find-food" /> 等支援的指令也能在沒有安裝機器龍的地方使用。
