機器龍重寫過一遍。指令的打法、設定的地方、還有一部分功能，都跟以前不一樣。

<Callout title="三句話講完">
大部分功能改用斜線指令。前綴指令沒有拿掉，但帶不了參數。舊的設定會搬過去，錢跟道具不會。
</Callout>

## 斜線指令怎麼用

在訊息框打一個 `/`，清單就跳出來。

<SlashCommandTour />

跟前綴指令比起來：

- **不用背指令名稱**。打幾個字就篩得出來
- **每個參數有名字**。不用記順序，也不會填到隔壁格
- **選錯 Discord 會擋**。身分組、頻道、成員這些參數只能從清單挑

## 前綴指令還在

`&` 開頭照樣能打，像這些：

<div className="not-prose my-4 flex flex-wrap gap-2 font-mono text-sm">
  {["&status", "&b", "&guild", "&avatar", "&banner", "&pick", "&1a2b", "&help", "&find-food"].map((command) => (
    <span key={command} className="rounded bg-fd-secondary px-2 py-1 text-fd-secondary-foreground">{command}</span>
  ))}
</div>

@ 機器龍也可以，像 `@YEE 式機器龍 status`。

前綴這條路有三個限制：

| 限制 | 說明 |
| --- | --- |
| 只讀指令名稱 | `&avatar @某人` 的 `@某人` 會被忽略，出來的是你自己的頭貼 |
| 只在伺服器裡 | 私訊和群組私訊只吃斜線指令 |
| 只有簡單指令 | 有子指令、或需要管理權限的指令走不了這條路 |

需要選人、選頻道、填數字的指令，因此都只能用斜線。

### 打了只能用斜線的指令會怎樣

機器龍不會回一句「沒有這個指令」，而是回一張卡片，列出這個指令現在的斜線用法。

| 類型 | 例子 | 原因 |
| --- | --- | --- |
| 有子指令 | `/poll create`、`/lol player` | 前綴語法沒地方放子指令名稱 |
| 要管理權限 | `/giveaway`、`/form`、`/clear` | 權限檢查交給 Discord，沒人繞得過 |

## 逐個指令設權限

這是前綴指令做不到的事。前綴指令對 Discord 來說就是一則普通訊息，擋不掉。

**伺服器設定 → 整合 → YEE 式機器龍**，每個指令旁邊都能單獨設定：

| 覆寫類型 | 效果 |
| --- | --- |
| 身分組 | 只有這些身分組能用這個指令 |
| 成員 | 指名某個人能用或不能用 |
| 頻道 | 這個指令只在特定頻道能用 |

常見用法：

- `/clear` 只開給管理員
- `/find-food` 只開在遊戲頻道，避免洗版
- `/giveaway` 只開給幹部

設定存在 Discord 那邊。機器龍改版、重新安裝，這些覆寫都不會掉。

## 投票整個換掉了

`&poll` 以前就是丟一行字出去，大家按表情符號。現在 <Cmd name="poll create" /> 送出後會跳一張表單，填完才發佈。

表單裡的欄位：

| 欄位 | 說明 |
| --- | --- |
| 標題 | 最多 100 字 |
| 選項 | 一行一個，2 到 18 個，每個 80 字以內，不能重複 |
| 描述 | 選填 |
| 結束時間 | 選填，像 `30m`、`2h`、`3d`。留空就手動結束 |

還有一個進階選單可以複選：**匿名投票**、**投票後不能改票**、**開票前保密**。

<PollFlowDemo />

票數會即時畫成一張圖片，每有人投一次就重畫。管理面多了六個子指令：

| 指令 | 用途 |
| --- | --- |
| <Cmd name="poll edit" /> | 改標題、描述、結束時間、圖片，或補開匿名 |
| <Cmd name="poll end" /> | 提前結束 |
| <Cmd name="poll resend" /> | 被洗版了，重發一次投票訊息 |
| <Cmd name="poll remove-vote" /> | 移掉某個人的票 |
| <Cmd name="poll role-weight" /> | 讓某個身分組一票抵多票 |
| <Cmd name="poll export" /> | 匯出一份 CSV，只有你看得到 |

細節在[投票](/zh-tw/docs/commands/poll)那頁。

## 收掉的功能

### 音樂

YouTube 這幾年一直擋機器人，撐到最後每天都在壞。`&play`、`&queue`、`&skip` 和歌單都不在了。

### 經濟和 RPG

舊系統有很難修的競態問題，同時操作會讓錢憑空多出來或消失。那些數字早就沒有意義。

接手的是 [`/find-food`](/zh-tw/docs/find-food)，帶 Yee 找食材、煮飯、餵它。跟舊系統完全分開算。

### 私人頻道

改用 [`/form`](/zh-tw/docs/commands/form)。開一張表單發佈，成員按按鈕就會開一條私人討論串。

表單不加題目也行，按鈕直接開討論串，跟以前的私人頻道一樣。

### 跨群聊天

把不同伺服器的頻道串成同一個聊天室的功能。維護成本高、濫用檢舉多，這次沒有跟著搬過來。

### 網頁控制面板

`app.yeecord.com` 收起來了。設定全部回到 Discord 裡面做。

當初搬到網頁是因為填表比打指令好用。後來 Discord 自己把斜線指令和表單做得夠好，多開一個網頁反而多一道手續。

## 舊資料的去向

| 項目 | 會怎樣 |
| --- | --- |
| 歡迎訊息、動態語音、身分組選單的設定 | 原封不動搬過去 |
| 舊訊息上的按鈕 | 照樣有反應 |
| 進行中的投票和抽獎 | 一起帶過去，設好的時間到就自動公布 |
| 錢、道具、寵物 | 不轉移，換成紀念徽章 |

<Callout type="warn" title="為什麼錢不轉移">
舊經濟的數字被競態 bug 汙染過，照搬只會把問題一起搬過來。取而代之的是「老朋友」紀念徽章，依照以前玩的深度分級，純紀念性質，不影響新遊戲平衡。
</Callout>

## 常見問題

### 為什麼打了指令沒反應

先確認機器龍還在不在伺服器裡。還在的話，到 **伺服器設定 → 整合** 看看這個指令有沒有被權限覆寫擋掉。

斜線清單裡完全找不到某個指令，通常是機器龍是舊的授權方式加進來的。重新安裝一次就會出現。

### 前綴指令帶參數為什麼沒用

前綴這條路只讀得到指令名稱，後面的字一律忽略。`&avatar @某人` 會給你自己的頭貼，`&quote` 因為一定要選人，乾脆連跑都跑不起來。要帶參數就用斜線指令。

### 舊的投票訊息還能按嗎

能。舊格式的按鈕有專門的相容路徑，票會算進同一份結果，不用重發。

只是舊訊息上就只有原本那幾顆按鈕：沒有單獨的收回票按鈕，票數也不會畫成圖片。想換成新版卡片，發起人打 <Cmd name="poll resend" /> 重發一次就好。

### 投票時間到了，卡片還顯示進行中

伺服器頻道裡的投票會自己更新。群組私訊是例外，機器龍改不動那裡的訊息，要等下一個人按下去，卡片才會重畫成已結束。票數不受影響。

### 我的錢真的沒了嗎

沒有消失，只是不換成新遊戲的貨幣。舊數字保留在紀念徽章的紀錄裡。

### 前綴可以改嗎

目前固定 `&`。@ 機器龍是另一個選擇。

還有問題就到 [支援伺服器](https://discord.gg/yeecord) 問。
